====================================================
GUÍA COMPLETA DE INSTALACIÓN Y SETUP DE SWAY (WAYLAND)
====================================================

Sistema objetivo:
- Fedora Linux (base del sistema)
- Entorno principal: Cinnamon
- Window Manager: Sway
- Enfoque: minimal, estable, estético y usable (daily driver)

NOTA:
Esta guía está pensada para una instalación Fedora + Sway y separa
los componentes necesarios de las aplicaciones opcionales.

====================================================
1. PREPARACIÓN DEL SISTEMA
====================================================

Antes de instalar el resto del setup:

sudo dnf upgrade --refresh -y

Reinicia si Fedora actualizó componentes importantes del sistema:

systemctl reboot

----------------------------------------------------
1.1 RPM FUSION
----------------------------------------------------

RPM Fusion es opcional y se recomienda instalarlo si vas a utilizar
paquetes multimedia o software que no esté disponible en los
repositorios oficiales de Fedora.

Instalación:

sudo dnf install -y \
https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

2. PAQUETES BASE
====================================================

CORE:

- sway
- waybar
- kitty
- wlogout
- swaylock
- swayidle
- swaybg
- fuzzel

UTILIDADES:

- brightnessctl        (control de brillo)
- pipewire              (audio)
- pipewire-pulseaudio   (compatibilidad con PulseAudio)
- wireplumber           (gestor de sesiones PipeWire)
- pavucontrol            (control gráfico de audio)
- grim                  (screenshots)
- slurp                 (selección con mouse)
- wl-clipboard          (wl-copy / wl-paste)
- gammastep             (filtro de luz azul)
- NetworkManager-tui    (nmtui)
- nm-connection-editor  (gestor gráfico de red)
- playerctl             (multimedia)
- upower                (batería / estado de carga)

INSTALACIÓN:

sudo dnf install -y \
sway waybar kitty wlogout swaylock swayidle swaybg fuzzel \
brightnessctl \
pipewire pipewire-pulseaudio wireplumber pavucontrol \
grim slurp wl-clipboard gammastep \
NetworkManager-tui nm-connection-editor \
playerctl upower

NOTA:
Fuzzel es el launcher principal de esta guía.
Wofi no se instala por defecto para evitar mantener dos launchers
que cumplen la misma función.

====================================================
4. SCRIPT PARA EVITAR WAYBAR DUPLICADO
====================================================

Archivo:

~/.config/sway/scripts/waybar.sh

Contenido:

#!/usr/bin/env bash

killall waybar 2>/dev/null
waybar &

Permisos:

chmod +x ~/.config/sway/scripts/waybar.sh

En sway/config:

exec_always ~/.config/sway/scripts/waybar.sh

NOTA:
Este script reinicia Waybar cada vez que Sway vuelve a cargar
la configuración.

24. LOCALSEND
====================================================

Instalar desde Flathub:

flatpak install flathub org.localsend.localsend_app

Ejecutar:

flatpak run org.localsend.localsend_app

IMPORTANTE:
NO desactives Firewalld para utilizar LocalSend.

LocalSend utiliza el puerto 53317 para la comunicación. Si
Firewalld bloquea la conexión, permite únicamente el tráfico
necesario:

sudo firewall-cmd --permanent --add-port=53317/tcp
sudo firewall-cmd --permanent --add-port=53317/udp
sudo firewall-cmd --reload

Comprobar Firewalld:

sudo systemctl status firewalld

Si Firewalld estaba deshabilitado, vuelve a activarlo:

sudo systemctl enable --now firewalld

27. AHORRO DE BATERÍA / PERFILES DE ENERGÍA
====================================================

IMPORTANTE:
No instalar power-profiles-daemon a ciegas.

Fedora puede utilizar distintos backends para la interfaz
powerprofilesctl, y en algunas instalaciones puede estar presente
tuned-ppd.

Primero comprueba qué tienes disponible:

powerprofilesctl list

Para ver el perfil actual:

powerprofilesctl get

Si powerprofilesctl funciona correctamente, utiliza los perfiles
que aparezcan en la lista.

Ejemplo de atajos en sway/config:

bindsym Mod1+F9  exec powerprofilesctl set power-saver
bindsym Mod1+F10 exec powerprofilesctl set balanced
bindsym Mod1+F11 exec powerprofilesctl set performance

NOTA:
No instales power-profiles-daemon si DNF indica que entra en
conflicto con tuned-ppd. En ese caso, conserva el backend que
Fedora ya está utilizando.

31. STOW PARA ADMINISTRAR DOTFILES
====================================================

Instalar:

sudo dnf install -y stow

Crear:

mkdir -p ~/dotfiles

IMPORTANTE:
La estructura de ~/dotfiles debe coincidir con la estructura que
quieres enlazar mediante GNU Stow.

Ejemplo:

~/dotfiles/
└── .config/
    ├── sway/
    ├── waybar/
    ├── fuzzel/
    └── kitty/

Entrar:

cd ~/dotfiles

Crear los enlaces:

stow .

Si tu estructura utiliza paquetes separados, por ejemplo:

~/dotfiles/
├── sway/
├── waybar/
├── kitty/
└── fuzzel/

entonces el comando puede variar según cómo quieras que Stow
cree los enlaces.

Antes de ejecutar stow sobre una configuración existente,
asegúrate de no tener archivos reales que entren en conflicto con
los enlaces.

brightnessctl set 50%

----------------------------------------------------
SI BRIGHTNESSCTL NO DETECTA EL BRILLO
----------------------------------------------------

Comprobar:

ls /sys/class/backlight/

Si aparece un dispositivo, comprobar nuevamente:

brightnessctl devices

Si no aparece ningún dispositivo, el problema puede estar
relacionado con el controlador de gráficos/kernel y no con
brightnessctl.

====================================================

El sistema utiliza PipeWire y WirePlumber.

Instalar:

sudo dnf install -y pipewire pipewire-pulseaudio wireplumber pavucontrol

----------------------------------------------------
ATAJOS DE VOLUMEN
----------------------------------------------------

En sway/config:

# Subir volumen
bindsym Ctrl+Shift+Right exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+

# Bajar volumen
bindsym Ctrl+Shift+Left exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-

# Silenciar / activar sonido
bindsym XF86AudioMute exec wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle

Si el teclado dispone de teclas multimedia:

bindsym XF86AudioRaiseVolume exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+

bindsym XF86AudioLowerVolume exec wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%-

bindsym XF86AudioMute exec wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle

----------------------------------------------------
COMPROBAR AUDIO
----------------------------------------------------

Ver dispositivos:

wpctl status

Ver volumen:

wpctl get-volume @DEFAULT_AUDIO_SINK@

Abrir mezclador gráfico:

pavucontrol

Comprobar PipeWire:

systemctl --user status pipewire

Comprobar WirePlumber:

systemctl --user status wireplumber

====================================================
ATAJOS DE SCREENSHOTS
====================================================

Los screenshots utilizan:

- grim
- slurp
- wl-clipboard

Instalar:

sudo dnf install -y grim slurp wl-clipboard

Crear directorio:

mkdir -p ~/Pictures

----------------------------------------------------
ATAJOS
----------------------------------------------------

Pantalla completa:

Print

Selección de región:

Shift + Print

Selección y copiar al portapapeles:

Ctrl + Shift + Print

----------------------------------------------------
CONFIGURACIÓN EN SWAY
----------------------------------------------------

# Pantalla completa
bindsym Print exec grim ~/Pictures/$(date +'%Y-%m-%d_%H-%M-%S').png

# Seleccionar región
bindsym Shift+Print exec grim -g "$(slurp)" ~/Pictures/$(date +'%Y-%m-%d_%H-%M-%S').png

# Seleccionar región y copiar al portapapeles
bindsym Ctrl+Shift+Print exec grim -g "$(slurp)" - | wl-copy

====================================================
WOB — OSD PARA VOLUMEN Y BRILLO
====================================================

Wob muestra indicadores en pantalla para valores como:

- Volumen
- Brillo
- Otros valores numéricos

Instalar:

sudo dnf install -y wob

----------------------------------------------------
USO
----------------------------------------------------

Wob normalmente recibe los valores desde scripts.

Los scripts de volumen y brillo pueden enviar el porcentaje
actual a Wob después de ejecutar el cambio.

Ejemplo conceptual:

brightnessctl set 5%+
brightnessctl -m

Para volumen:

wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+
wpctl get-volume @DEFAULT_AUDIO_SINK@

----------------------------------------------------
NOTA
----------------------------------------------------

Si tus dotfiles ya contienen scripts para Wob, utilizar esos
scripts en lugar de crear otros diferentes.

La configuración de Wob debe mantenerse en:

~/.config/wob/

====================================================
PERFILES DE ENERGÍA
====================================================

NO instalar power-profiles-daemon a ciegas.

Primero comprobar qué proveedor de perfiles está utilizando
Fedora:

powerprofilesctl list

Consultar el perfil actual:

powerprofilesctl get

Los perfiles disponibles pueden incluir:

performance
balanced
power-saver

El controlador puede aparecer como:

Driver: platform_profile

----------------------------------------------------
ATAJOS
----------------------------------------------------

En sway/config:

bindsym Mod1+F9 exec powerprofilesctl set power-saver

bindsym Mod1+F10 exec powerprofilesctl set balanced

bindsym Mod1+F11 exec powerprofilesctl set performance

----------------------------------------------------
IMPORTANTE
----------------------------------------------------

Si DNF informa de un conflicto entre power-profiles-daemon
y tuned-ppd, NO fuerces la instalación.

Mantén el backend que Fedora ya está utilizando.

====================================================
STOW PARA ADMINISTRAR DOTFILES
====================================================

Instalar:

sudo dnf install -y stow

Crear el directorio:

mkdir -p ~/dotfiles

----------------------------------------------------
ESTRUCTURA
----------------------------------------------------

Las configuraciones que quieras administrar mediante Stow deben
estar dentro de:

~/dotfiles/

Por ejemplo:

~/dotfiles/
├── .config/
│   ├── sway/
│   ├── waybar/
│   ├── fuzzel/
│   └── kitty/
└── ...

----------------------------------------------------
MOVER CONFIGURACIONES
----------------------------------------------------

Si estás migrando una configuración existente, primero mueve
las configuraciones que quieras administrar desde ~/.config
hacia ~/dotfiles respetando la estructura correspondiente.

IMPORTANTE:

No sobrescribas archivos existentes sin comprobar primero
qué contiene cada uno.

----------------------------------------------------
ACTIVAR DOTFILES
----------------------------------------------------

Entrar:

cd ~/dotfiles

Ejecutar:

stow .

Stow creará los enlaces simbólicos correspondientes.

Comprobar:

ls -la ~/.config/
